      操作指南
      1. 打開同一個工作
        一瞥 → 展開 → 觀察。也可用數字鍵 1、2、3。快速切換可中斷並接續轉場。
      2. 建立工作與審查成果
        觀察可切換摘要與可信詳細事件。新增工作後讀取後端進度。成果保存後，再接受、拒絕或提出調整。停止要求仍需執行端確認取消。

        成果可展開閱讀、拖動標題及右下角調整空間；專注閱讀填滿瀏覽器。方向鍵可移動／調整，Esc 關閉。右上角切換黑曜、煙茶、月白與動態偏好。觀察指標反光和靜態模式的差異。
